# A jugar se dijo · Ecosistema digital de transferencia

Propuesta digital de transferencia del conocimiento (Opción A: experiencia educativa exitosa) basada en la **capacitación para docentes de primaria de la Mesa Pedagógica de Educación Física de San Vicente Ferrer, Antioquia (lunes 29 de octubre de 2012)**.

**Sitio público (tras activar GitHub Pages):** https://jgomez-lgtm.github.io/a-jugar-se-dijo/

## Contenido

| Carpeta / archivo | Qué contiene |
|---|---|
| `index.html` | Dossier interactivo: 5 ejes, guía de transferencia, evidencia de impacto, kit REA con buscador de 44 juegos, videoteca y archivo 2012 |
| `recursos/guia-transferencia.md` | Paso a paso para replicar la jornada de 6 h y aplicar el kit en clase |
| `recursos/fichas/` | Fichas de juego de un minuto |
| `recursos/plantilla-sesion.md` | Formato de planeación de sesión (basado en la sesión 4.° y 5.° de la Mesa, 2013) |
| `recursos/rubrica.md` | Rúbrica saber / saber hacer / ser, con 4 niveles |
| `recursos/indicadores.md` | KPIs de apropiación y formulario sugerido |
| `datos/juegos.csv` | Los 44 juegos de la cartilla: número, edad mínima, capacidad |
| `archivo-2012/` | Documentos históricos del paquete de memorias |

## Cómo aportar

1. Haz un *fork* del repositorio o envía tu variante por el grupo de la comunidad.
2. Usa la plantilla de ficha (`recursos/fichas/_plantilla.md`).
3. No incluyas fotos de estudiantes sin autorización escrita de sus acudientes (Ley 1098 de 2006).
